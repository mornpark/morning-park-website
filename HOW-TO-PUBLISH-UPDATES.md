# How to Publish Website Updates

Every time you change index.html or any file in this folder,
run these 3 lines in Terminal to push it live:

```
git add .
git commit -m "Your update description"
git push
```

Replace "Your update description" with a quick note about what changed.
Example: `git commit -m "Updated pricing and added new photo"`
